# Passport OS 定制版 · 命海拾遗

面向 **FoloToy AI Passport** 的社区定制固件，当前版本为
`1.0.0`。这是清理历史模块、统一当前交互后形成的首个稳定语义化版本：
保留日常工具和语音操作能力，对首页、应用选择方式、历法应用和个人使用体验
进行了较大幅度的重构。

适用硬件为 ESP32-C3、8 MB Flash、240×320 显示屏、无 PSRAM 的
FoloToy AI Passport。外观相似但硬件配置不同的开发板不能直接套用。

## 项目来源

本项目根据 [manchunx7-bit/passport-os](https://github.com/manchunx7-bit/passport-os)
的 **Passport OS `0.2.0-rc.59`** 改造而来，对应上游提交
[`5101891c0521`](https://github.com/manchunx7-bit/passport-os/commit/5101891c05210557217dd068fd3d78121a6e4175)。

它不是从零开始实现的固件，也不是 FoloToy 官方原版。当前仓库是在上游代码
基础上，按“命海拾遗”的首页风格、八字与万年历需求以及精简应用列表的方向
继续开发和验证的定制版本。

## `1.0.0` 版本重点

- 应用选择页改为 **Passport Flow** 整页轮播：一次聚焦一个应用，支持
  单击逐项移动、长按跨四项、换页回弹和确认打开动效。
- 开机画面改为“命海日出”：金色太阳、几何海浪、星点与 14 格启动节奏，
  全部由 LVGL 图形对象绘制，不增加位图资源。
- 启动器精简为 8 个应用入口，首页作为系统底座保留在轮播之外。
- 首页提供命海拾遗、极简四柱、天气生活和人物志四套布局。
- 事项清单统一为全机唯一清单，支持完成、单项删除和清除已完成。
- 八字排盘和万年历均可离线使用，日期详情包含十二时辰干支。
- 保留六套整机主题、早晚子时、真太阳时、语音控制和个人资料设置。
- 移除 Muse、AI 随身语音和三个声音小游戏，并清理对应入口与遗留配置。

`1.0.0` 是当前源码版本号，不表示对应镜像已经发布。镜像必须重新构建，
并通过当前状态文档记录的布局、SRAM 和真机检查后才能作为安装包交付。

## 安装与升级

只刷入与 FoloToy AI Passport、ESP32-C3、8 MB Flash、240×320 屏幕和现有
分区表匹配的镜像。先备份设备；默认升级应保留 Wi-Fi、个人资料和设备身份。

| 场景 | 镜像 | 写入地址 |
| --- | --- | --- |
| 首次安装或明确全清 | `FoloToy-AI-Passport-full.bin` | `0x0` |
| 已确认分区一致、需要保留数据 | `passport-os.bin` | `0x10000` |

完整镜像会覆盖其写入范围内的配置；“全清”还应先执行整片擦除。普通升级
只写应用区，并在写入和读回校验后确认非应用区未变化。具体工具、备份和
恢复流程见 [维护说明](docs/MAINTENANCE.md)。

首次启动后，手机连接 `Passport-WiFi-xxxx` 热点并打开
`http://192.168.4.1`，完成 Wi-Fi、城市和个人资料设置。

## 当前功能一览

首页之外，启动器包含 8 个入口：

启动器采用 **Passport Flow** 整页轮播。顶部固定显示“选择应用”，每页聚焦
一个大图标、一个应用标题和右侧上、下、确定三键指示；左侧位置轨标记页序。
上下键短按逐项移动，长按跨四项，确定键播放收束动画后打开当前应用，
长按确定返回首页。

| 应用 | 主要用途 |
| --- | --- |
| 小智 AI | 语音对话、设备控制、媒体与应用启动、提醒和事项清单管理、AI 热点与资讯 |
| 城市收音机 | 按城市查找网络电台、播放广播、设置睡眠停止 |
| 网易云音乐 | 登录个人账号、搜索歌曲、播放收藏、歌单和每日推荐 |
| 备忘提醒 | 创建一次或重复提醒、到时响铃和延后 |
| 事项清单 | 一个清单管理全部事项，支持完成、删除和清除已完成 |
| 八字排盘 | 输入出生资料，查看四柱、大运和流年 |
| 万年历 | 1900–2100 年月历、日干支、农历、节气和日期详情 |
| 设置 | 音量、亮度、熄屏、主题、子时规则、Wi-Fi、按键音效和设备重置 |

首页不在上述 8 个入口中。开机且已有 Wi-Fi 时直接进入首页；在首页短按确定
进入应用选择页，长按确定在应用选择页可返回首页。

## 当前版本重点

### 1. Passport Flow 应用选择页

应用选择页不再一次展示全部应用，也不要求用户在小卡片中辨认焦点。当前交互为：

- 每页只显示一个应用，使用大图标圆环和应用身份色。
- 顶部固定显示“选择应用”及 Wi-Fi、电池状态。
- 左侧位置轨显示全部应用及当前页位置。
- 右侧上箭头、下箭头和 OK 圆键对应当前设备的三个实体按键，并在按压时反馈。
- 上下键短按切换一个应用，长按一次跨越四项。
- 确定短按打开应用；长按确定返回首页。
- 换页使用 220 ms 整页滚动，并配合图标缩放回弹、色光和确认收束动画。

应用页面退出时会释放对应 LVGL 对象。收音机、网易云音乐和小智等重型应用还会
经过连续内存检查，必要时先整理堆再启动。

### 2. 首页改为“命海拾遗”

首页顶部名称由 `PASSPORT` 改为 **“命海拾遗”**，并重构为四柱历、
时间与天气信息、每日一句三个主要区域。

首页提供四套可在“设置 → 首页样式”中切换并保存的布局：

- **命海拾遗**：四柱、天气和每日一句的完整信息首页。
- **极简四柱**：强调当天四柱和农历的大字布局。
- **天气生活**：突出城市天气、体感、湿度和空气质量的布局。
- **人物志**：左侧彩色人物照，右侧姓名、天气与简短介绍；底部显示今日时间、
  农历、节气和年月日时干支。

人物志照片可在手机设置页选择、拖动和缩放，页面会裁成严格的 3:4 比例并转换为
108×144 RGB565 小图。设备只保存这一张约 31 KB 的显示图，不保存手机原图；
支持替换和删除，上传中断时保留原照片。

日期与干支区域采用四列布局：

```text
年   月   日   时
丙   己   庚   辛
午   亥   子   巳
```

- 四列分别显示年、月、日、时；天干和地支上下对齐，便于快速扫读。
- 天干、地支根据五行使用不同颜色显示。
- 干支下方显示当前农历日期。
- 支持在设置中切换 **早子时 / 晚子时**，首页与八字排盘会使用同一规则。
- 只有当天确实交节时才显示“今日交某节气”；普通日期不常驻显示当前节气。
- 显示距离下一个节气还有多少天。
- 已移除“丙午马年”等与当前阅读关系较弱的生肖年信息。

首页右侧保留当前时间、日期、城市、Wi-Fi 状态，以及天气信息：

- 温度、天气状态和天气图标。
- 湿度、风向、风级和 PM2.5。
- 进入首页后自动获取天气，无需每次手动点击更新。
- 天气约每 15 分钟自动刷新，空气质量约每 30 分钟刷新；联网失败后会稍后重试。
- 城市发生变化时会重新获取对应位置的天气和空气质量。
- 首次未设置城市时默认使用 **北京**。
- 可按下键切换操作提示、天气详情、更新时间、数据来源等信息。

首页底部改为 **每日一句**：

- 从网络获取一句较短的、有思考空间的中文内容。
- 单行时垂直居中；两行时按两行居中排版。
- 不再显示“每日一句”标题、作者、“佚名”等附加文字。
- 当天内容会缓存；网络失败或内容不可用时使用内置精选短句。
- **长按上键**换一句，**长按下键**进入设置。
- 首页主操作提示为“上干支 · 下名言 · 确定应用”；副提示为
  “长按上换句 · 长按下设置”。

姓名、签名、城市与坐标在手机设置页维护。人物志布局会显示姓名和签名，其他
三套布局继续以历法和天气为主；首页短按上键用于手动更新天气。

### 3. 八字排盘

八字排盘是一款独立的离线应用，资料只在本次开机期间保留，退出应用或返回
资料页后仍可继续调整并重新排盘。

出生资料支持：

- 性别滚动选择：男、女。
- 历法选择：公历、农历；农历支持闰月。
- 出生年和月逐项调整，出生年每次只滚动 1 年。
- 出生日根据当月实际天数校验，31 日、闰年 2 月等日期可以正确选择；
  切换月份或年份后，超出当月天数的日期会自动收敛。
- 出生时按小时调整，出生分逐分钟调整。
- 支持 10 个出生城市。
- 支持早子时、晚子时。
- 支持标准时和真太阳时，默认使用 **真太阳时**。
- 默认资料为 `1990-01-01 12:00`，可在排盘前完整修改。
- 排盘支持 1900–2100 年。

命盘显示：

- 年、月、日、时四柱，天干和地支使用大字号显示。
- 四柱区域不绘制表格线。
- 显示公历时间、城市、性别和对应农历日期。
- 不显示十神、藏干、五行分布、日主等扩展信息。
- 显示大运正向或逆向排列、起运年份和 10 个大运。
- 大运横向排列，每一列下方显示该大运对应的流年。
- 流年按 4 行一组滚动，下键下两行，上键回看。
- 当前大运和当前流年使用背景和边框强调。
- 命盘页可长按确定返回出生资料，继续保留原有输入并重新排盘。

八字功能完全离线，不依赖天气、短句或语音服务。当前小智语音尚未接入八字排盘
指令，排盘需要在应用内完成。

### 4. 万年历

万年历覆盖 1900–2100 年，所有农历、干支和节气数据均内置，可离线使用。

月历：

- 每格使用两行大字显示：14px 公历日、12px 日干支。
- 每个日期格都显示当天日干支。
- 今天使用强调色；选中日期使用背景色和完整边框区分。
- 交节当天的公历日使用红色提示。
- 网格下方显示选中日期的农历，以及距离下一个节气的天数。
- 普通月份显示 5 周；6 周月份选择到最后一行时，网格自动上移一行，
  保证第 6 周完整可见。

日期详情：

- 公历日期、星期和农历日期。
- 农历闰月信息。
- 年柱、月柱和日柱。
- 当天发生的节气，以及下一节气倒计时。
- 十二时辰按 `6 列 × 2 行` 展示：每格显示时间范围、时干和时支，
  天干在上、地支在下，不重复显示“子时、丑时”等名称。
- 时干与时支分别按木、火、土、金、水着色；查看今天时高亮当前时辰。

操作：

- 上下短按选择前后一天。
- 确定短按打开日期详情，再按确定返回月历。
- 长按上键回到今天。
- 长按下键打开年月跳转。
- 长按确定退出应用。

### 5. 设置与整机行为

- 提供 **早子时 / 晚子时** 选项，同时作用于首页和八字排盘。
- 默认城市为北京。
- 首页天气进入后自动更新，保留失败重试与城市切换后的立即刷新。
- 提供“命海拾遗”“极简四柱”“天气生活”“人物志”四套首页样式，可在设置中切换并保存。
- 提供经典绿、旅行仪器、像素白、霓虹黑、宣纸朱砂、青金守夜六套主题。
- 支持音量、亮度、自动熄屏时间、短按唤醒和按键音效设置。
- 支持手机配网、设备手动选网、已存网络管理，以及网络、时间和电量诊断。
- 长时间无操作会按设置熄屏；支持长按上键开机。
- 设备会根据当前应用调整 Wi-Fi 省电档；退出媒体或语音应用时处理音频资源，
  避免 ESP32-C3 连续内存不足。
- 设备设置可恢复默认值，Wi-Fi 和个人资料会保留。

## 去除的功能

相对上游 `Passport OS 0.2.0-rc.59`，本项目去除了以下 5 个独立功能：

| 已去除功能 | 原用途 | 当前状态 |
| --- | --- | --- |
| Muse | 将语音发送给 Muse，并在设备屏幕阅读回复 | 应用入口、显示界面和运行逻辑已移除 |
| AI 随身语音 | 将设备作为电脑的语音输入工具 | 应用入口及配套交互已移除 |
| 你在狗叫什么 | 用声音参与的小游戏 | 应用和启动器入口已移除 |
| 声音跳一跳 | 根据声音长短控制跳跃的小游戏 | 应用和启动器入口已移除 |
| 俄罗斯方块 | 堆叠方块、消行的小游戏 | 应用和启动器入口已移除 |

设备升级后会清理 Muse 遗留配置，避免旧凭据继续留在设备上。Muse 和
AI 随身语音所需的账号、手机配对、代理或 Windows 配套程序也不再需要。

首页同时去除了以下展示和交互：

- 不再把个人档案卡作为首页左侧主区域。
- 移除了首页人像、随身名片及对应上传、存储和图片解码功能。
- 不再常驻显示不在当天发生的节气。
- 不再显示“丙午马年”等生肖年标签。
- 每日一句不再显示标题、作者和“佚名”等附属文字。

## 保留并继续提供的功能

### 小智 AI

- 双击确定进入语音对话，设备负责录音、上传、播放回复和对话界面显示。
- 可调整音量、亮度，打开应用或返回首页。
- 可搜索并播放自己的网易云音乐，也可按城市和关键词寻找网络电台。
- 可创建一次或重复提醒，并支持延后。
- 可添加、读取、修改和删除事项，也可一次清除全部已完成事项。
- 可查询 AI 热点、AI 新闻和 AI 日报，并直接朗读摘要。
- 对话界面包含机器人表情、聆听声波，以及可展开的长文本。
- 切换到其他应用或开始媒体播放后，本轮语音对话结束；再次双击确定可继续。
- 语音能力需要联网并配置可用的小智服务。

### 城市收音机

- 根据当前城市或手动选择的城市查找网络电台。
- 上下选择电台，确定开始或停止播放。
- 显示播放状态和音量。
- 支持睡眠计时，到时间后停止广播。
- 支持通过小智按城市、电台名或节目类型切换电台。

### 网易云音乐

- 使用使用者自己的网易云账号。
- 搜索歌曲并按歌曲标题和歌手匹配。
- 播放自己的歌单、收藏和每日推荐。
- 长按上键播放/暂停，长按下键切换下一首，长按确定退出应用。
- 支持通过小智搜索音乐、选择歌曲和设置播放时长。
- 播放需要 Wi-Fi、有效账号和第三方接口可用。

### 备忘提醒

- 创建一次提醒或按日重复提醒。
- 保存日期、时间、标题和重复规则。
- 到时在设备上提示并响铃。
- 支持延后提醒、检查即将到期项目，并处理关机期间积压的提醒。
- 可通过小智创建、查询、修改和删除提醒。
- 可离线保存和触发，前提是设备保持开机且时间已校准。

### 事项清单

- 全机只有一份事项清单，不再要求选择或创建命名清单。
- 可按批次添加事项、编辑文字、标记完成和单独删除。
- 长按下键删除当前事项，长按上键清除全部已完成事项。
- 支持稳定事项编号、并发 revision 保护和重启后恢复。
- 支持最多 60 条事项，容量不足时明确提示。
- 可通过小智读取、添加、修改和删除事项。
- 可离线使用。

### 手机设置与 Wi-Fi

- 首次开机可连接设备热点并打开 `http://192.168.4.1` 完成配网。
- 选择家庭 Wi-Fi、城市并保存个人资料。
- 可为“人物志”首页选择一张彩色照片，并拖动、缩放成 3:4 显示区域。
- 照片保存在设备存储区，支持替换和删除；上传失败不会破坏上一张照片。
- 配网页同时提供全国城市目录，也支持手机定位或手动输入坐标。
- 可从设备设置进入已存网络列表和网络诊断。

### 状态与电源

- 顶部状态栏显示 Wi-Fi 信号和电池电量。
- 低电量时提示并限制屏幕亮度；电量耗尽后关机。
- 支持自动熄屏和短按唤醒。
- 支持音量、亮度、主题和按键音效反馈。
- 媒体、语音和普通应用使用不同的 Wi-Fi 省电策略。

## 离线与联网范围

| 功能 | 是否需要网络 |
| --- | --- |
| 首页干支、农历、节气和时钟 | 不需要 |
| 每日一句 | 需要；失败时使用内置短句 |
| 首页天气和 PM2.5 | 需要 |
| 八字排盘 | 不需要 |
| 万年历 | 不需要 |
| 备忘提醒、事项清单 | 不需要，但提醒依赖设备时间 |
| 城市收音机、网易云音乐 | 需要 |
| 小智语音、AI 热点与资讯 | 需要，并需要可用的小智服务 |
| Wi-Fi 配网、城市和个人资料设置 | 配网阶段需要连接设备热点 |
| 人物志彩色照片 | 配网或修改资料时需连接设备热点；显示不需要网络 |

天气、空气质量、每日一句、电台目录、网易云音乐、AIHOT 资讯和小智服务属于
第三方能力，实际可用性取决于对应服务和当前网络。
