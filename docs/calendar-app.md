# 万年历

本地离线万年历，覆盖 1900–2100 年。

## 月历

- 每格使用大字号显示公历日和日干支。
- 交节日期使用警示色显示日期。
- 今天使用强调色，选中日期使用背景和边框区分。
- 选中日期的农历与下一节气倒计时显示在网格下方摘要行。
- 普通月份显示五周；六周月份在选中最后一周时自动上移一行。

## 日期详情

- 公历日期和星期。
- 农历月日，包含闰月。
- 年柱、月柱和日柱。
- 当天节气事件及下一节气倒计时。
- 十二时辰按 6 列 × 2 行显示，每格只有时间范围、时干和时支；
  天干在上、地支在下。
- 时干与时支分别按五行着色；查看今天时，当前时辰使用背景和边框强调。

## 按键

| 操作 | 月历 | 日期详情 |
| --- | --- | --- |
| 上/下短按 | 前后选择一天 | 前后查看一天 |
| 确定短按 | 打开日期详情 | 返回月历 |
| 上键长按 | 回到今天 | 回到今天 |
| 下键长按 | 打开年月跳转 | 打开年月跳转 |
| 确定长按 | 退出应用 | 返回月历 |

年月页面通过上下键选择字段，确定进入编辑；长按下键直接跳转，长按确定返回月历。

## 数据

农历和干支复用八字应用的离线历法核心；二十四节气使用独立的 1900–2100 数据表。所有功能离线可用，不写网络数据或出生资料。
