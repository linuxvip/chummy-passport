# 当前状态

仓库：<https://github.com/linuxvip/chummy-passport>

## 平台与功能

- 硬件：FoloToy AI Passport，ESP32-C3、8 MiB Flash、240×320 显示，无 PSRAM。
- 工具链：ESP-IDF 5.5.3、LVGL 9.5、FreeRTOS。
- 启动器：小智 AI、城市收音机、网易云音乐、番茄钟、秒表、备忘提醒、清单、八字排盘、设置。
- 首页：“命海拾遗”四柱与农历、交节当天提示、下一节气倒计时、时钟、天气和空气质量、每日一句。
- 小智：WebSocket 语音对话、Opus 音频、设备控制和本地 MCP 工具。
- 八字：公历/农历、性别、早晚子时、标准时/真太阳时、10 个城市、四柱、大运和流年。
