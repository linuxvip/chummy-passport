# 当前状态

仓库：<https://github.com/linuxvip/chummy-passport>

## 平台与功能

- 硬件：FoloToy AI Passport，ESP32-C3、8 MiB Flash、240×320 显示，无 PSRAM。
- 工具链：ESP-IDF 5.5.3、LVGL 9.5、FreeRTOS。
- 开机画面：“命海日出”金色太阳从几何海浪上升起，配星点、扫入式的
  `PASSPORT OS`、24px“命海拾遗”标题和 14 格启动节奏；全部使用 LVGL
  图形对象绘制，不增加位图资源。
- 启动器：支持 Passport Flow 整页轮播与应用网格两种风格，可在设置中切换并保存，默认保留 Passport Flow。Passport Flow 顶部固定显示“选择应用”；每页只保留大图标圆环、
  编号和英文分类、应用标题。左侧保留放大的应用彩色位置轨；右侧上箭头位于上方、下箭头
  位于中间偏下、OK 圆键位于屏幕右下角，三者与设备物理键一一对应并显示按压反馈。右侧
  不再显示独立滚动条。页面底色固定，不随应用切换改变；只有图标、圆环、
  标题、位置轨和按键反馈使用应用身份色；图标圆环使用 2px 描边。不显示应用文字说明或底部操作提示。
  支持 220 ms 换页、图标缩放回弹、全页色光过渡、长按跨四项和确认后的页面收束动画。
  确认进入的整卡缩放仅在最大连续块 ≥96 KB 时启用；低于该值时只缩放 64px 图标，避免低连续内存下申请大块缓冲而卡死。
  应用网格使用固定 3×4 网格，一屏显示当前 10 个应用、最多容纳 12 个；短按逐项、长按跨行，当前项使用
  应用身份色外框、短线、低透明度表面底和高亮标题；未选中项不显示底板，
  打开时只收缩 48px 图标。
- 首页：提供“命海拾遗”“极简四柱”“天气生活”“人物志”四套布局，可在设置中切换并保存。人物志包含一张彩色人物照、姓名、签名、城市天气、农历与今日干支。
- 手机设置：2.4 GHz Wi‑Fi 配网、全国城市目录、姓名、签名、城市与坐标，以及单张人物志照片的选择、3:4 裁切、替换和删除。
- 事项清单：全机只有一份清单；支持添加、完成、单独删除和清除全部已完成事项，旧的五份命名清单会自动展开迁移。
- 小智：WebSocket 语音对话、Opus 音频、设备控制和本地 MCP 工具。
- 八字：公历/农历、性别、早晚子时、标准时/真太阳时、10 个城市、四柱、大运和流年。
- 六爻：起卦方式使用 240×320 竖屏，不要求选择事项类别；时间法直接按当前设备时间成盘，手动摇卦以三枚钱币逐爻摇六次，保留钱面与 6/7/8/9 并支持 0–6 个动爻。确认后切换为 320×240 横屏，显示本卦/变卦、六神、六亲纳甲、世应、居中的旬空和伏神；无动爻时只显示本卦。确定进入双卦白话解释，卦意页的本卦/变卦标签与解读正文使用 16px，不设单爻详参页。
- 万年历：1900–2100 两行大字月历，每格显示公历和日干支；日期详情包含 6×2 十二时辰时干支表，时干、时支按各自五行着色，年月跳转继续保留。
- 手机遥控：独立桌面应用，设备作为 BLE HID 外设连接手机，无需伴侣 App。默认媒体模式发送
  上一媒体 / 下一媒体 / 播放暂停，长按上/下键切换到方向键模式（上/下方向与空格）。设备以
  `Passport R2`、独立随机地址和 Just Works 加密绑定出现，无需 PIN；界面采用对等双键布局，
  显示连接状态、设备电量、当前模式、最近操作，并在按键时提供卡片闪亮和箭头位移反馈。
  BLE 仅在前台启用；受 ESP-IDF 5.5.3 在此硬件上动态拆卸 NimBLE 的故障影响，退出时停止
  广播、断开连接、停止 NimBLE host 后受控重启并恢复首页。
- 主题：经典绿、旅行仪器、像素白、霓虹黑、宣纸朱砂、青金守夜六套整机配色，保存在 NVS。

## 边界

- 八字资料不写 NVS，只在本次开机期间保留。
- 八字目前支持 10 个出生城市。
- 小智语音八字排盘暂未实现。
- 六爻盘面不写 NVS，只在本次开机期间保留；应用不收集问事类别或事项正文。时间法和手动摇卦规则以 [六爻设计文档](liuyao-app-design.md) 为准。
- 网易云部分大响应接口使用 HTTP，账号 Cookie 在不可信网络中存在暴露风险。
- `storage` 分区为 256 KiB，当前只用于保存一张 108×144 RGB565 人物志照片（31,104 字节）。
- 纯 BLE HID 无法读取手机电量；界面显示的是本机电量、连接状态和最近操作。手机电量需要
  伴侣 App 或自定义双向 GATT 服务。
- 天气、每日一句、电台、网易云、AI 资讯和小智依赖第三方服务。
